Removed apps on Unihertz Jelly Star (2026-10-28)

Method: adb shell pm uninstall -k --user 0 <package>
These are system apps, so this hides them for the current user only. The APKs stay
in the system partition. Restore one with:
  adb shell cmd package install-existing <package>
A factory reset (and sometimes a system update) also restores them.

Restore everything:
  for p in com.google.android.apps.youtube.music com.google.android.apps.tachyon \
    com.google.android.apps.bard com.google.android.videos com.google.android.keep \
    com.google.android.projection.gearhead com.google.android.gms.supervision \
    com.google.android.printservice.recommendation com.google.android.feedback \
    com.google.android.gms.location.history com.google.android.marvin.talkback \
    com.google.android.googlequicksearchbox com.agui.game com.agui.studentmodel \
    com.agui.circlesearch com.android.fmradio com.example.feedback; do
    adb shell cmd package install-existing $p
  done
